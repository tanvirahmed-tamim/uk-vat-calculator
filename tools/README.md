# Site standards

The pages in this repository are static HTML, generated by the build scripts in the
`vat-build` working folder. These three tools keep the published site consistent with
the rules below and are safe to run at any time.

## Rules

1. **Extensionless URLs.** Internal links, `rel="canonical"`, `og:url`, JSON-LD `url`,
   `@id`, `mainEntityOfPage`, `isPartOf`, `itemListElement` and every sitemap `<loc>`
   use the extensionless form, for example `/guides/vat-rates` and
   `https://vatinuk.co.uk/guides/vat-rates`. `index.html` is `/`. Cloudflare Pages
   serves these from the `.html` file with a 200 and redirects the `.html` path, so a
   canonical ending in `.html` points at a redirect.
2. **Root icon tags.** Every page carries six root-absolute tags: `/favicon.ico`,
   `/favicon.svg`, `/favicon-192.png`, `/favicon-512.png`, `/apple-touch-icon.png` and
   `/site.webmanifest`.
3. **Contact by email.** `contact@vatinuk.co.uk` is the route for corrections,
   questions and feedback. There is no public issue tracker and no GitHub link.
4. **British English and GBP.** Copy uses British spelling, prices use `£` and HMRC
   figures and rates, nothing invented.
5. **No dashes.** Zero em dashes, en dashes or dash entities in any file. Use a colon,
   a comma, `to` for ranges, or a plain hyphen in compound names such as `GB-NI`.

## Tools

```powershell
node tools/normalise-urls.js           # rewrite links and icon tags in every page
node tools/normalise-urls.js --check   # report what would change, exit 1 if any
node tools/build-redirects.js          # regenerate _redirects from the pages on disk
node tools/qa-standards.js             # full standards gate, exit 1 on any problem
```

Run `normalise-urls.js` and `build-redirects.js` after adding or renaming a page, then
`qa-standards.js` before committing. The page generators call the same normaliser, so
new output is extensionless by default even if a template still writes `.html`.
